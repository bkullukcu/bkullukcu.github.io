# Berkay Kullukçu — Portfolio Website

## Primary pages
- `/` — Homepage
- `/selected-work/` — Engineering case studies
- `/experience/` — professional experience and technical capabilities
- `/talks/` — conference presentations, with embedded recordings
- `/research-outputs/` — Publications, patents, thesis, and session-chair record
- `/contact/` — contact and CV links

## Role-focused application links
- `/audio/`
- `/test-validation/`
- `/signal-processing/`

English is the default. The EN/DE selection is saved in the visitor’s browser.

## Conference video
The current recordings are stored locally in `videos/`. For multiple future recordings, use unlisted YouTube videos and replace the local video object in `data/en.json` and `data/de.json`.

## Deploy
Copy all files to the root of the `bkullukcu.github.io` repository, commit, and push.
